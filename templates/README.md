# AGENTS reference

Read [AGENTS.md](AGENTS.md) for principles worth comparing with your existing
instructions. It is not part of the default copy or edit selection.

Offer specific lessons and explain their benefit to the project. General adoption
approval does not authorize editing an existing AGENTS.md. Apply only targeted
additions the user explicitly selects, preserving all other content. If the file
is absent, offer creation separately rather than creating it automatically.

The library's root AGENTS.md is a maintenance guide, not an installation template.
Other [guides](../docs/agent-guidelines/README.md) can be adopted independently;
adding them does not require changing AGENTS.md or inserting a reference map.
