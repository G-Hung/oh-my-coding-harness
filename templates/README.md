# AGENTS template

Copy or merge [AGENTS.md](AGENTS.md) into your project's root instructions after
approval. It contains first principles and a small map to focused guidance.

Copy useful guides from [agent guidelines](../docs/agent-guidelines/README.md),
then keep only pointers to files present in your project and adjust their paths.
The principles work without the guides. Add essential project context and exact
check commands; retain existing useful rules.
