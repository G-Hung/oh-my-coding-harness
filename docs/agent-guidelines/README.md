# Agent guidelines

Detailed instructions to copy individually and adapt to your project. Each
document includes its own procedure; the links below are navigation for this
library, not dependencies you must copy together.

| Reference | Read when |
| --- | --- |
| [Workflow](workflow.md) | Starting work, reviewing, or handing off changes |
| [Verification](verification.md) | Selecting checks, profiling tests, or running a local server |
| [Documentation](documentation.md) | Behavior, interfaces, ownership, or editing guidance changes |
| [Code style](code-style.md) | Implementing or refactoring code |
| [Safety](safety.md) | Work touches data, credentials, migrations, or external effects |

Use [weekly sweep](../weekly-sweep.md) for findings-only maintenance. Use the
[README standard](../readme-standard.md) for useful subsystem documentation.

## Adoption

After approval, copy selected documents or sections, then add your project's
commands, conventions, and constraints. Keep only applicable guidance. If you
add a reference map to your project's AGENTS.md, link only to files you adopted
or that already exist. The complete ship procedure lives in the standalone
[ship-cycle skill](../../adapters/codex/.agents/skills/ship-cycle/SKILL.md).
